# Emberway

A 2D platformer built in Unity where you help a young dragon find its way home.

## Built With
- Unity 6.3 LTS
- C# / Unity 2D URP
- Aseprite

## Status
In development

## Architecture Highlights
- Event-driven design with generic EventBus<T>
- Component-based entity system
- Finite state machines for game and player states
